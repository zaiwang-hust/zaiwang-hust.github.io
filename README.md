# Zai Wang

Personal homepage: https://zaiwang-hust.github.io/

An ocean-blue interactive gallery and academic profile, built as a single `index.html` with inline CSS, JavaScript, SVG and a Canvas globe. No build step or external libraries are required.

## Explore

- Drag the HUST globe, or focus it and use arrow keys to rotate.
- Press Space to pause or resume; use the controls to reset, enter immersive view or save a PNG.
- Press Ctrl/Command + K for quick navigation.
- Switch between light and dark themes. Reduced-motion preferences are respected.

## Update

Edit the profile, research interests and honors in `index.html`. GitHub Pages publishes the root of `main`.

Public profile content is based on information supplied by Zai Wang. The interactive artwork is a personal homepage study.
